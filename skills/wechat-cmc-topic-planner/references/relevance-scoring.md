# 选题关联度评分规则

这份规则判断候选内容是否属于“信使引擎”的主线，以及它能为 mRNA CMC、LNP 递送或相邻技术方向提供何种工艺和质量决策价值。关联度独立于证据可信度和传播潜力。

## 纳入范围

### 核心

- mRNA、saRNA、circRNA 的 IVT、加帽、纯化、完整性、纯度、效力、稳定性和分析方法；
- LNP 的脂质、处方、混合、粒径、包封、偶联、靶向、递送、放大、稳定性和质量控制；
- 直接改变上述 CMC 或递送决策的方法、材料、监管要求和技术进展。

### 桥接

- 体内 CAR-T；
- 靶向递送和细胞亚群选择性；
- mRNA/LNP 与其他递送或载荷组合后，对工艺、质量或控制策略有直接迁移价值的主题。

非 LNP 的病毒载体、siRNA、ADC 或通用生物制药内容只有在能直接解释或改进 mRNA/LNP 工艺、分析或质量控制时才纳入。泛 AI、融资、管线盘点、市场预测和没有工艺/质量决策价值的内容排除。

## 必过门槛

候选必须能够形成以下形式的决策句：

`在 [对象或环节] 中，[变量或异常] 会如何影响 [结果]，读者应如何验证或控制？`

合格判断至少包含一项：工艺参数、CQA/CPP、分析方法、可比性、稳定性、纯度、效力、包封、粒径、靶向选择性或控制策略。

若内容只说明机制、疗效、融资、管线或行业趋势，但没有可执行的技术判断，则标记为背景。机制或临床内容只有在明确改变 CQA/CPP 理解、分析方法或工艺控制时才通过。

## 双轴评分

两个轴分别按照 `0-4` 分评分。不要因为一个轴得分高，就自动抬高另一个轴。

### mRNA CMC 轴

| 分数 | 判断 | 示例 |
| ---: | --- | --- |
| 0 | 与 mRNA 的分子质量、工艺或质量控制无关 | 只讨论 LNP 材料本身，不涉及 RNA 载荷或产品控制 |
| 1 | 只提到 mRNA，或只属于泛递送背景 | 一般性介绍 mRNA 技术，没有工艺或质量动作 |
| 2 | 提供机制或技术背景，但没有具体 CMC 决策 | mRNA 翻译机制、表达持续时间，但没有方法或控制含义 |
| 3 | 能支持一个具体 CMC 判断 | 某种杂质影响效力，建议增加特定纯度或效力检测 |
| 4 | 直接定义或改变核心 CMC 决策 | 建立 IVT 副产物与 CQA 的关系，改变放行、可比性或控制策略 |

### LNP 递送轴

| 分数 | 判断 | 示例 |
| ---: | --- | --- |
| 0 | 与 LNP 或其他颗粒递送无关 | 纯 mRNA 分析化学，没有递送或制剂内容 |
| 1 | 只提到 LNP，或只属于泛递送背景 | LNP 行业进展，没有处方、工艺或控制判断 |
| 2 | 提供机制或技术背景，但没有具体递送决策 | 内吞路径或生物分布机制，没有验证或控制建议 |
| 3 | 能支持一个具体递送或制剂判断 | 配体密度影响内化，建议增加表面配体表征或用特定细胞确认 |
| 4 | 直接定义或改变核心递送决策 | 处方或工艺变量改变靶向、稳定性或效力，改变 CPP/CQA 或控制策略 |

`X` 表示公开材料不足，不能判断。`X` 不是 0，也不能按 0 参与公式。

## 资格门槛

符合以下任一条件才具备正式候选资格：

- 任一轴达到 4 分；
- 两轴均达到 3 分。

单轴 3 分且另一轴低于 3 分时，只有在明确的跨模态迁移价值时进入桥接观察，不得直接进入正式选题池。

## 关联分

使用脚本计算，避免手算偏差：

```text
关联分 = 100 × (0.75 × max(轴1, 轴2) + 0.25 × min(轴1, 轴2)) ÷ 4
```

四舍五入到一位小数。

| 关联分 | 等级 | 处置 |
| ---: | --- | --- |
| 90-100 | 双核心 | 优先进入综合选题评估 |
| 75-89 | 核心候选 | 进入综合选题评估 |
| 60-74 | 桥接候选 | 仅进入桥接观察，除非明确证明跨模态迁移价值，否则不得进入正式选题池 |
| 0-59 | 淘汰 | 不进入选题池 |

任一轴为 `X` 时不生成正式关联分，输出“暂定”并列出补齐材料。

## 证据分

证据分只表示来源可信度，不改变关联轴分数。采用支撑关键判断的最高质量且可直接核验的证据。

| 等级 | 证据分 | 来源 |
| --- | ---: | --- |
| A | 4 | 同行评审论文、正式法规和监管政策、可核验的专利全文 |
| B | 3 | 预印本、会议摘要、临床试验注册、公司技术文档 |
| C | 1 | 行业媒体、公司宣传或无法回查原始来源的材料 |
| D | 0 | 只有推断、无来源或无法核验 |

只有当关键判断由至少一项 A 级证据直接支持时，才能把证据分记为 4。多个低等级来源不能相加成 A 级。

## 动作矩阵

| 关联结果 | 证据分 | 默认动作 |
| --- | ---: | --- |
| 关联分 >= 75 | 3-4 | 立即深挖或进入选题池，再按综合分排序 |
| 关联分 >= 75 | 0-1 | 待核验，持续追踪，不得直接进入主线 |
| 关联分 60-74 | 3-4 | 仅在跨模态迁移价值明确时进入桥接观察 |
| 其他 | 任意 | 淘汰或标注为背景 |

以下任一情况直接淘汰：

- 无法形成工艺/质量决策句；
- 两轴均低于 3 分；
- 只有营销、融资、管线、奖项或泛趋势信息；
- 关键判断无法回到可核验来源；
- 论文型候选的 DOI 已出现在跨报告 DOI 台账中；同一主题但 DOI 不同不因此直接淘汰。

## 信息不足与置信度

- **高**：有摘要或全文，能够引用原文证据；两轴均可判断；来源和日期完整。
- **中**：关键内容可判断，但一个轴为暂定，或证据主要来自 B 级。
- **低**：只有标题、二手摘要或不可核验来源。

低置信度不得标为“立即深挖”。信息不足时保留 `X` 和缺口，不用常识填补。
